# Core V2 Phase Records

Active task state moved to [`../NOW.md`](../NOW.md) on 2026-08-19. Phase order
and exit outcomes moved to [`../ROADMAP.md`](../ROADMAP.md).

Files in this directory are frozen execution records from the former tracker
workflow. They preserve detailed decomposition, deviations, and audit chronology
at their recorded revision; they are not current status or contract authorities.
They remain the historical authority for what an existing `Pxx-Tnnn` task ID
meant and for its recorded dependency decomposition. When `NOW.md` activates
one of those tasks, it copies the current completion check and immediate
dependency there instead of treating the frozen status column as live state.

- [Phase 0A: baseline and render contracts](phase-00a-baseline-and-render-contracts.md)
- [Phase 0B: migration inventories and project contracts](phase-00b-inventories-and-project-contracts.md)
- [Phase 1: experimental Sound Core](phase-01-experimental-sound-core.md)
- [Phase 2: minimal compiled voice graph](phase-02-minimal-compiled-voice-graph.md)

New active work is not given another tracker. Add its bounded slice to `NOW.md`,
and preserve the completed phase outcome in the formal exit review.
