| Field         | Value      |

| Status        | Active     |

This ledger records identities and references crossing project, GUI, MCP, history, serialization, import, duplication,
and engine boundaries.

## Problems to flag

- raw primitives used as domain identities;
- type- or order-encoded strings;
- positional references;
- IDs reused across domains;
- display names used as identity;
- runtime slots persisted as identity;
- references repaired heuristically at load time;
- duplication/import behavior without explicit remapping.

## Ledger

Entries use `IDN-NNNN` identifiers. Next free identifier: `IDN-0032`.

Pass 1 derived producers, consumers, and encodings from the committed project schema (`schemas/project.schema.json`) and
the declaring Rust types. `Migration` is left blank throughout: it is the output of ADR-0014, not an input to it.

  ADR-0035).

  `Patch` type already covered by `IDN-0016`..`IDN-0022`, so it adds no new identity; a field-level confirmation is
  still owed.
- **Tracker-module import** — lives on the unmerged `feat/tracker-import` branch and is **not present at
  `dd69b657`**. Out of scope for an audit of `main`; it must be re-audited before that branch merges.

  were not.
