# Identity and Reference Inventory

| Field         | Value      |
|---------------|------------|
| Status        | Active     |
| Phase         | 00B        |
| Last reviewed | 2026-09-08 |

This ledger records identities and references crossing project, GUI, MCP, history, serialization, import, duplication,
and engine boundaries.

## Problems to flag

- raw primitives used as domain identities;
- type- or order-encoded strings;
- positional references;
- IDs reused across domains;
- display names used as identity;
- runtime slots persisted as identity;
- references repaired heuristically at load time;
- duplication/import behavior without explicit remapping.

intended owner, a reorder retargets a reference, or an intentional index is promoted to entity identity without a
consumer. False source claims, contradictions and unresolved contract holes block adoption of the affected rule;

  assignments remain copied. Nodes belong to each graph's own map (`mod_grid.rs::ModGraph`), so this operation

  internal endpoints and metadata. The retain/clear policy for external track assignments remains a separate
  authoring decision; this pass makes no audible-equivalence or random-state claim.
