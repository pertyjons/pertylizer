# Core V2 Working Agreement (superseded)

The active Core V2 workflow moved to [`PROCESS.md`](PROCESS.md) on 2026-08-19.
This stable path remains so historical ADRs, phase records, and reviews retain a
valid link. It is not an additional authority.

Use:

- [`PROCESS.md`](PROCESS.md) for evidence, decision, review, and gate rules;
- [`NOW.md`](NOW.md) for active task state;
- [`ROADMAP.md`](ROADMAP.md) for phase outcomes and order.

## Phase gates

Historical links to this heading now resolve to the gate rules in
[`PROCESS.md`](PROCESS.md#evidence-and-gates).

## Review protocol

Historical reviews that cite this section refer to the former requirements to
state scope before editing, change the authoritative record first, run the
smallest relevant checks, use an independent reader, and reread every semantic
repair against its direct consumers. The current equivalent is
[`PROCESS.md`](PROCESS.md#review-stopping-rule) together with the repository
review rules in [`AGENTS.md`](../../AGENTS.md#review-and-design-protocol).

## Semantic stopping condition

Under the former agreement, review stopped when the declared criteria were
verified and no contract, authority, safety, or correctness change remained.
Editorial improvements alone did not keep it open. The same condition is now
the [current review stopping rule](PROCESS.md#review-stopping-rule).
